Artgine

Artgine은 Electron 기반 개발 앱과 웹 서버, 렌더링 엔진, 프로젝트 생성 도구를 하나로 묶은 통합 개발 환경입니다. 프로젝트 경로를 선택하고, 렌더링 옵션과 포함 라이브러리를 설정한 뒤, Run(F9)으로 바로 실행 흐름을 확인할 수 있습니다.

GitHub Agent Sample ULPC

앱이 담당하는 일

Artgine 앱은 프로젝트 설정, 실행, 서버 접속 정보 확인, 생성 파일 구조 안내까지 개발 흐름을 한 화면에 모읍니다.

프로젝트 실행

projectPath를 선택하고 Run(F9)으로 프로젝트 HTML과 서버 실행 흐름을 시작합니다.

렌더링 설정

targetWidth, targetHeight, Renderer, Canvas, XR, 개발자 옵션을 UI에서 조정합니다.

Include / Plugin

Bootstrap, Monaco, Excel, Firebase 같은 라이브러리와 엔진 플러그인을 선택합니다.

서버 모드

URL, Private IP, Public IP, QR 정보를 확인하고 브라우저로 바로 열 수 있습니다.
