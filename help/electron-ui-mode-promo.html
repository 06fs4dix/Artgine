Artgine

Artgine은 Electron 기반 개발 앱과 웹 서버, 렌더링 엔진, 프로젝트 생성 도구를 하나로 묶은 통합 개발 환경입니다. 프로젝트 경로를 선택하고, 렌더링 옵션과 포함 라이브러리를 설정한 뒤, Run(F9)으로 바로 실행 흐름을 확인할 수 있습니다.

GitHub UI Guide Agent

앱이 담당하는 일

Artgine 앱은 프로젝트 설정, 실행, 서버 접속 정보 확인, 생성 파일 구조 안내까지 개발 흐름을 한 화면에 모읍니다.

프로젝트 실행

projectPath를 선택하고 Run(F9)으로 프로젝트 HTML과 서버 실행 흐름을 시작합니다.

렌더링 설정

targetWidth, targetHeight, Renderer, Canvas, XR, 개발자 옵션을 UI에서 조정합니다.

Include / Plugin

Bootstrap, Monaco, Excel, Firebase 같은 라이브러리와 엔진 플러그인을 선택합니다.

서버 모드

URL, Private IP, Public IP, QR 정보를 확인하고 브라우저로 바로 열 수 있습니다.

초기 셋업

콘솔 설치

clone, install, start로 개발 앱을 실행합니다.

GUI 실행

Windows는 start.bat, Linux/macOS는 start.sh로 시작할 수 있습니다.

서버만 실행

Electron UI 없이 `npm run start_web`으로 웹 서버만 띄웁니다.

개발 모드

App

실행 경로, URL, 크기, 실행 프로그램, 서버 방식을 정합니다.

Preference

렌더러와 개발 옵션, XR, Canvas 같은 실행 환경을 조정합니다.

Include / Plugin / AI

라이브러리, 엔진 플러그인, AI 도구 구성을 선택합니다.

서버 모드

서버 화면은 접속 URL, Private IP, Public IP, QR 코드를 보여줍니다. 같은 네트워크나 외부 장치에서 접속해야 할 때 필요한 정보를 빠르게 복사할 수 있습니다.

소스 수정 법

Run(F9)이 자동 생성하는 영역과 직접 수정해야 하는 영역을 구분합니다. TypeScript와 HTML의 EntryPoint 아래를 중심으로 프로젝트 코드를 관리합니다.

Artgine으로 바로 시작

엔진, 개발 앱, 웹 서버, PWA 설정을 한 프로젝트 안에서 관리합니다.
