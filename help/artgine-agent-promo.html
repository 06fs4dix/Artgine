Artgine Agent

Artgine의 Home 화면에서 원격 화면, 파일, AI 작업을 한 번에 다루는 로컬 웹 인터페이스입니다.
RDP, Files, AI(Chat/Term/Web)를 한 화면에서 제공합니다.

GitHub 튜토리얼 기능 살펴보기

주요 기능

RDP, Files, AI를 중심으로 작업 상태 확인부터 실행까지 하나의 화면에서

RDP F3

Local 또는 원격 Home.html 서버의 화면을 확인합니다. 입력 모드를 켜면 키보드와 마우스가 대상 화면으로 전달됩니다.

Files F1/F2

허용된 서버 폴더를 탐색하고 파일 보기, 편집, 검색, 공유, 업로드, Git/SVN 작업을 처리합니다.

File Manager / Search

F1은 File Manager, F2는 파일 검색입니다. 검색 결과에서 위치로 이동하고, 관리 메뉴에서 루트 선택과 버전 관리 작업을 실행합니다.

AI Chat

Working Directory와 옵션을 정한 뒤 AI 채팅 세션을 시작합니다. 여러 세션을 동시에 두고 상태 색상으로 연결 상태와 응답 상태를 확인합니다.

Term / Schedule

cmd, codex, claude, opencode 같은 CLI 세션을 관리합니다. 반복 작업은 Schedule로 등록합니다.

Web 세션

확인할 URL, 유지 시간, 화면 크기를 정해 웹 화면을 열고 화면과 동작 기록을 확인합니다. 입력을 켜면 키보드와 마우스를 전달할 수 있습니다.

사용 예시

AI에게 자연어로 지시만 하면 됩니다

크로스 디바이스
PC에서 작업 중인데 모바일로 접속해서 마무리해줘

외출 중에도 스마트폰 브라우저로 접속해 PC 작업을 그대로 이어받습니다.

원격 디버깅
지금 PC 화면에 에러창 떠 있는데 확인하고 해결해줘

RDP로 현재 PC 화면을 캡처해 에러 내용을 파악하고 즉시 수정합니다.

웹 자동화
사이트에 로그인해서 메일 확인하고 비밀번호 변경해줘

Web 세션으로 브라우저를 원격 조작해 반복 웹 작업을 자동 처리합니다.

영구 지시
이 폴더 작업할 때 권한 확인 메시지 무시해줘

특정 폴더나 조건에 대한 규칙을 한 번 지시해두면 세션 내내 유지됩니다.

스케줄 + 파일 정리
매일 자정마다 다운로드 폴더를 날짜별로 자동 정리해줘

스케줄러에 등록하면 AI가 지정 시각마다 파일 탐색·이동·정리를 자동 실행합니다.

원격 서버 작업
운영 서버에 접속해서 로그 분석하고 에러 원인 찾아줘

서버에서 원격 서버로 직접 접속해 로그를 읽고 에러 패턴을 분석해 원인을 보고합니다.

시작하기

두 가지 방법으로 바로 시작할 수 있습니다

방법 1 전체 설치 & 실행
# 클론
git clone --recursive https://github.com/06fs4dix/Artgine-Agent.git
# 설치
cd Artgine && npm install
# 실행
npm start # → http://localhost:8050

웹 서버만 실행하려면 npm run start_web [포트] (기본 포트 8050)

방법 2 실행파일 다운로드
Windows
https://github.com/06fs4dix/Artgine-Agent/releases/download/AI/Artgine-win32-x64.zip
Linux
https://github.com/06fs4dix/Artgine-Agent/releases/download/AI/Artgine-linux-x64.zip

다운로드 후 압축을 풀고 Artgine을 실행하세요.
