Artgine Agent

Artgine의 Home 화면에서 원격 화면, 파일, AI 작업을 한 번에 다루는 로컬 웹 인터페이스입니다.
RDP, Files, AI(Chat/Term/Web)를 한 화면에서 제공합니다.

GitHub 튜토리얼 기능 살펴보기

주요 기능

RDP, Files, AI를 중심으로 작업 상태 확인부터 실행까지 하나의 화면에서

RDP F3

Local 또는 원격 Home.html 서버의 화면을 확인합니다. 입력 모드를 켜면 키보드와 마우스가 대상 화면으로 전달됩니다.

Files F1/F2

허용된 서버 폴더를 탐색하고 파일 보기, 편집, 검색, 공유, 업로드, Git/SVN 작업을 처리합니다.

File Manager / Search

F1은 File Manager, F2는 파일 검색입니다. 검색 결과에서 위치로 이동하고, 관리 메뉴에서 루트 선택과 버전 관리 작업을 실행합니다.

AI Chat

Working Directory와 옵션을 정한 뒤 AI 채팅 세션을 시작합니다. 여러 세션을 동시에 두고 상태 색상으로 연결 상태와 응답 상태를 확인합니다.

Term / Schedule

cmd, codex, claude, opencode 같은 CLI 세션을 관리합니다. 반복 작업은 Schedule로 등록합니다.

Web 세션

확인할 URL, 유지 시간, 화면 크기를 정해 웹 화면을 열고 화면과 동작 기록을 확인합니다. 입력을 켜면 키보드와 마우스를 전달할 수 있습니다.

시작하기

3단계로 바로 실행할 수 있습니다

# 1. 클론
git clone --recursive https://github.com/06fs4dix/Artgine.git
# 2. 설치
cd Artgine && npm install
# 3. 실행
npm start # → http://localhost:8050

웹 서버만 실행하려면 npm run start_web [포트]
