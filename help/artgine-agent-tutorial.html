Artgine Agent

최신 Home은 RDP, Files, AI를 한 화면에서 사용하는 로컬 웹 인터페이스입니다. 이 튜토리얼은 현재 주요 작업 흐름만 다룹니다.

RDP

Local 또는 원격 Home.html 서버의 화면을 바로 확인하고, 입력 모드를 켜면 키보드와 마우스를 전달합니다.

Files

허용된 서버 폴더를 탐색하고, 파일 보기/편집, 검색, 공유, 업로드, Git/SVN 작업을 처리합니다.

AI

Chat, Term, Web 하위 탭에서 AI 채팅, 웹 터미널, 웹 화면 원격 확인을 관리합니다.
