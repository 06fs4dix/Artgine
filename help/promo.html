Artgine-Agent

Artgine 엔진 위에서 동작하는 웹 기반 에이전트 인터페이스입니다.
파일 탐색·편집, AI 채팅, 웹 터미널, 원격 브라우저 디버깅을 하나의 PWA에서 통합 제공합니다.

GitHub 튜토리얼 기능 살펴보기

주요 기능

파일 관리와 AI 에이전트를 하나의 창에서

파일 탐색기 F3

서버의 파일을 탐색·관리합니다. 폴더 이동, 이미지·오디오·비디오 재생, 코드·문서 편집을 지원합니다. 버전 관리(Git/SVN) 상태 배지로 변경 현황을 한눈에 확인할 수 있습니다.

파일 검색 + VCS F1 F2

F1 File Manager 모달로 파일 추가·삭제·업로드. F2 재귀 검색(최대 200개 결과, 중지 버튼 제공). Git/SVN diff·update·add·revert·commit·push를 웹 UI에서 직접 실행합니다.

멀티 AI 채팅

Claude·Codex·Antigravity·OpenCode 4종 제공자 지원. 멀티 세션 동시 운용. 세션 상태 색상: 미연결 · 처리 중 · 대기 중. 실시간 응답, 파일 첨부, 마크다운 렌더링.

웹 터미널

최대 9개 동시 세션. cmd claude codex antigravity opencode 5가지 모드. F6 SUPER 모드(에이전트 명령 자동 승인). F7 입력 바 포커스.

원격 브라우저 디버깅

실시간 화면 공유, 콘솔·네트워크 로그 수집. 마우스(이동·클릭·드래그·휠)·키보드 원격 제어. URL 파라미터로 읽기 전용 공유 링크 생성 가능.

스케줄러

터미널 세션에 cron 스타일 명령을 등록하여 타이머 주기로 자동 반복 실행. 지연(delay)·횟수(count)·시작(start)·종료(end) 오프셋 설정으로 정밀한 작업 스케줄링.

시작하기

3단계로 바로 실행할 수 있습니다

# 1. 클론
git clone --recursive https://github.com/06fs4dix/Artgine-Agent.git
# 2. 설치
cd Artgine-Agent && npm install
# 3. 실행
npm start # → http://localhost:8050

웹 서버만 실행하려면 npm run start_web [포트]
